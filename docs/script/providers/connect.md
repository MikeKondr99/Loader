# Connect

`Connect` читает источник данных по имени подключения из реестра подключений.

В скрипте всегда указывается имя:

```ts
FROM Connect('connection_name')
```

или:

```ts
FROM Connect(name='connection_name')
```

Поведение зависит не от синтаксиса `Connect`, а от типа подключения, который настроен снаружи скрипта.

## Виды подключений

| Вид | Документация | Что читает |
| --- | --- | --- |
| База данных | [connect-database.md](connect-database.md) | SQL-запрос во внешнюю БД. |
| Файл | [connect-file.md](connect-file.md) | Готовую таблицу или SQL-фрагмент в целевом DWH. |
| Папка | [connect-folder.md](connect-folder.md) | Файл внутри подключенной папки. |

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `text` | обязателен | Имя подключения в registry. Можно передать позиционно: `Connect('dev_postgres')`. |

Остальные параметры зависят от вида подключения.

## Ошибки

Если подключение не найдено, resolver вернет ошибку и попробует подсказать близкое имя из реестра.

Если подключение найдено, но скрипт использует неподходящий режим, ошибка формулируется через пользовательский вид подключения:

```text
Подключение Файл 'dwh_orders' не поддерживает SQL после FROM.
Подключение Папка 'shared' требует параметр path='relative/path'.
```
