# Union

`Union` объединяет несколько уже загруженных script-таблиц через `UNION ALL`.

Поля сопоставляются по логическим именам, а не по физическому порядку колонок в ClickHouse.

## Минимальный пример

```ts
first:
LOAD *
FROM Inline(id, name; 1, 'Alice');

second:
LOAD *
FROM Inline(id, name; 2, 'Bob');

all_users:
LOAD *
FROM Union(first, second);
```

## Синтаксис

```ts
Union(table1, table2)
Union(table1, table2, table3)
```

`Union` принимает только позиционные имена таблиц без кавычек.

Для имен с пробелами или спецсимволами используйте bracket-name:

```ts
all_orders:
LOAD *
FROM Union([orders 2026], [orders archive]);
```

## Поведение полей

Общий список полей строится по именам из всех входных таблиц.

Если в одной из таблиц поля нет, `Union` подставляет `NULL`.

Если типы одноименных полей отличаются, они приводятся к общему доменному типу:

| Типы | Результат |
| --- | --- |
| одинаковые типы | исходный тип |
| `Text` с любым типом | `Text` |
| `Number` с числовыми типами | `Number` |
| `Integer` и `Boolean` | `Integer` |
| прочие несовместимые сочетания | `Text` |

Все поля результата становятся nullable, потому что часть таблиц может не содержать часть колонок.

SQL после `FROM Union(...)` не поддерживается.
