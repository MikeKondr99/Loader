# Numbers

`Numbers` генерирует последовательность целых чисел.

Provider создает одну колонку `number` типа `Int64`.

## Минимальный пример

```ts
numbers:
LOAD *
FROM Numbers(10);
```

Результат: числа от `0` до `10` включительно.

## Полный пример

```ts
odd_numbers:
LOAD
  number
FROM Numbers(min=1, max=9, step=2);
```

Результат: `1`, `3`, `5`, `7`, `9`.

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `max` | `int` | обязателен | Последнее допустимое значение последовательности. |
| `min` | `int` | `0` | Первое значение последовательности. |
| `step` | `int` | `1` | Шаг последовательности. Должен быть больше `0`. |

## Позиционные параметры

```ts
FROM Numbers(10);        // max=10
FROM Numbers(1, 10);     // min=1, max=10
FROM Numbers(1, 10, step=2);
```

`max` должен быть больше или равен `min`.

SQL после `FROM Numbers(...)` не поддерживается.
