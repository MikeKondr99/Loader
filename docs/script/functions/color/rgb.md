# Rgb

`Rgb` создает цвет из RGB-компонентов.

## Rgb(r, g, b)

`Rgb(r, g, b)` принимает три целых числа и возвращает `int` в формате `0xFFRRGGBB`.

Alpha всегда равен `0xFF`.

Каждый компонент приводится к диапазону `0..255`: значения меньше `0` становятся `0`, значения больше `255` становятся `255`.

Если любой аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Rgb(0, 0, 0)` | `0xFF000000` |
| `Rgb(255, 255, 255)` | `0xFFFFFFFF` |
| `Rgb(255, 0, 0)` | `0xFFFF0000` |
| `Rgb(0, 255, 0)` | `0xFF00FF00` |
| `Rgb(0, 0, 255)` | `0xFF0000FF` |
| `Rgb(1, 2, 3)` | `0xFF010203` |
| `Rgb(256, 0, 0)` | `0xFFFF0000` |
| `Rgb(257, 2, 3)` | `0xFFFF0203` |
| `Rgb(-1, 0, 0)` | `0xFF000000` |
| `Rgb(0, -1, 0)` | `0xFF000000` |
| `Rgb(0, 0, -1)` | `0xFF000000` |
| `Rgb(null, 0, 0)` | `null` |
| `Rgb(0, null, 0)` | `null` |
| `Rgb(0, 0, null)` | `null` |
| `Type(Rgb(1, 2, 3))` | `'int!'` |
