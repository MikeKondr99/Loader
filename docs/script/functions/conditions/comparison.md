# Comparison

Операторы сравнения значения одного типа.

`=`, `!=` поддерживают `int`, `num`, `text`, `date`.

`<`, `>`, `<=`, `>=` и `Between` поддерживают `int`, `num`, `date`.

Если один из операндов сравнения равен `null`, результат `null`.

## Оператор меньше `<`

`<` проверяет, что левое значение строго меньше правого.

Примеры:

| Expression | Result |
| --- | --- |
| `5 < 10` | `true` |
| `10 < 5` | `false` |
| `1.5 < 1.3` | `false` |
| `1.3 < 1.5` | `true` |
| `-4.0 < -2.0` | `true` |
| `Date('2026-01-01') < Date('2026-01-02')` | `true` |
| `Date('2026-01-02') < Date('2026-01-01')` | `false` |
| `5 < Int(null)` | `null` |

## Оператор больше `>`

`>` проверяет, что левое значение строго больше правого.

Примеры:

| `1.5 > 1.3` | `true` |
| `1.3 > 1.5` | `false` |
| `-2.0 > -4.0` | `true` |
| `Date('2026-01-02') > Date('2026-01-01')` | `true` |
| `Date('2026-01-01') > Date('2026-01-02')` | `false` |
| `5 > Int(null)` | `null` |

## Оператор равно `=`

`=` проверяет равенство.

Сравнение `null = null` тоже возвращает `null`, а не `true`.

Примеры:

| Expression | Result |
| --- | --- |
| `5 = 5` | `true` |
| `5 = 10` | `false` |
| `1.5 = 1.5` | `true` |
| `1.5 = 1.3` | `false` |
| `-4.0 = -4.0` | `true` |
| `'abc' = 'abc'` | `true` |
| `'abc' = 'ABC'` | `false` |
| `Date('2026-01-01') = Date('2026-01-01')` | `true` |
| `Date('2026-01-01') = Date('2026-01-02')` | `false` |
| `5 = Int(null)` | `null` |
| `Text(null) = Text(null)` | `null` |

## Оператор не равно `!=`

`!=` проверяет неравенство.

Сравнение `null != null` тоже возвращает `null`, а не `false`.

Примеры:

| Expression | Result |
| --- | --- |
| `5 != 10` | `true` |
| `5 != 5` | `false` |
| `1.5 != 1.3` | `true` |
| `1.5 != 1.5` | `false` |
| `-4.0 != -2.0` | `true` |
| `'abc' != 'ABC'` | `true` |
| `'abc' != 'abc'` | `false` |
| `Date('2026-01-01') != Date('2026-01-02')` | `true` |
| `Date('2026-01-01') != Date('2026-01-01')` | `false` |
| `5 != Int(null)` | `null` |
| `Text(null) != Text(null)` | `null` |

## Функция `Between`

`Between(value, min, max)` проверяет, что `value` находится в диапазоне `[min, max]` включительно.

Если `value`, `min` или `max` равен `null`, результат `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `5.Between(1, 10)` | `true` |
| `15.Between(1, 10)` | `false` |
| `Between(5, 1, 10)` | `true` |
| `Between(15, 1, 10)` | `false` |
| `1.5.Between(1.0, 2.0)` | `true` |
| `0.9.Between(1.0, 2.0)` | `false` |
| `1.Between(1, 10)` | `true` |
| `10.Between(1, 10)` | `true` |
| `0.Between(1, 10)` | `false` |
| `11.Between(1, 10)` | `false` |
| `5.Between(1.5, 10.5)` | `true` |
| `Between(5.5, 1, 10)` | `true` |
| `Date('2026-01-02').Between(Date('2026-01-01'), Date('2026-01-03'))` | `true` |
| `Date('2026-01-04').Between(Date('2026-01-01'), Date('2026-01-03'))` | `false` |
| `Date('2026-01-01').Between(Date('2026-01-01'), Date('2026-01-03'))` | `true` |
| `Date('2026-01-03').Between(Date('2026-01-01'), Date('2026-01-03'))` | `true` |
| `Int(null).Between(1, 10)` | `null` |
| `5.Between(Int(null), 10)` | `null` |
| `5.Between(1, Int(null))` | `null` |
