# ApplyMap

`ApplyMap` возвращает значение из mapping-таблицы по ключу.

Mapping-таблица создается отдельной инструкцией `MAPPED LOAD`. С точки зрения пользователя это словарь: первое поле является ключом, второе поле является значением.

`ApplyMap` может использовать только `MAPPED LOAD`, который объявлен раньше текущего statement.

## value.ApplyMap(map)

`value.ApplyMap(map)` ищет `value` в mapping-таблице `map`.

`map` должен быть константным именем mapping-таблицы.

Если ключ найден, результат имеет тип второго поля mapping-таблицы.

`ApplyMap` можно использовать в `SELECT`, `WHERE`, `GROUP BY` и `ORDER BY`, если тип результата подходит для этого места.

Если ключ не найден, результат `null`.

Если нужен fallback для отсутствующего ключа, используется обычный `Alt`.

Если ключ равен `null`, результат `null`, но тип ключа должен быть понятен заранее. `null.ApplyMap('map')` без явного типа запрещен; нужно писать, например, `null.Text().ApplyMap('map')`.

Если таблица не найдена или она не является `MAPPED LOAD`, script завершится ошибкой.

Если тип ключа не совпадает с типом первого поля mapping-таблицы, script завершится ошибкой.

## Пример

```ts
[Названия показателей]:
MAPPED LOAD *
FROM Inline(
  ключ, название;
  'выручка', 'Выручка';
  'себестоимость', 'Себестоимость продаж';
  'маржа', 'Маржинальность'
);

[Показатели]:
LOAD
  показатель,
  показатель.ApplyMap('Названия показателей') AS название,
  показатель.ApplyMap('Названия показателей').Alt('Неизвестный показатель') AS [название с fallback]
FROM Inline(
  показатель;
  'выручка';
  'себестоимость';
  'нет такого'
);
```

Результат:

| показатель | название | название с fallback |
| --- | --- | --- |
| выручка | Выручка | Выручка |
| себестоимость | Себестоимость продаж | Себестоимость продаж |
| нет такого | null | Неизвестный показатель |
