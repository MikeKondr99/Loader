# DbVersion

`DbVersion` возвращает версию внутренней базы выполнения.

## DbVersion()

`DbVersion()` возвращает строку версии ClickHouse.

Точное значение зависит от окружения, поэтому его не стоит использовать как бизнес-значение в модели.

Примеры:

| Expression | Result |
| --- | --- |
| `DbVersion()` | строка версии, например `'24.8.14.39'` |
