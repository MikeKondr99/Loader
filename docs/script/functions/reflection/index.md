# Reflection Functions

Reflection functions помогают увидеть, как Loader и ClickHouse понимают выражение.

Эти функции полезны для отладки скрипта, проверки типов и диагностики неожиданных преобразований.

## Функции

- [Type](/docs/script/functions/reflection/type.md) - доменный тип выражения в Loader.
- [RawType](/docs/script/functions/reflection/raw-type.md) - физический тип выражения в ClickHouse.
- [DbName](/docs/script/functions/reflection/db-name.md) - имя внутренней базы выполнения.
- [DbVersion](/docs/script/functions/reflection/db-version.md) - версия внутренней базы выполнения.
