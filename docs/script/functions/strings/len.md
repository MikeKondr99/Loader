# Len

`Len` возвращает длину строки.

## Len(value)

`Len(value)` возвращает количество Unicode-символов в строке.

Если вход равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Len('')` | `0` |
| `Len('a')` | `1` |
| `Len(' x   ')` | `5` |
| `Len('abc')` | `3` |
| `Len('привет')` | `6` |
| `Len('😀')` | `1` |
| `Len('a\tb')` | `3` |
| `Len(null)` | `null` |
