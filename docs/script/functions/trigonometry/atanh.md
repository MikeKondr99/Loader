# Atanh

`Atanh` возвращает гиперболический арктангенс.

## Atanh(value)

`Atanh(value)` принимает `num` строго больше `-1` и строго меньше `1`.

Если входной аргумент равен `null`, результат тоже `null`.

Если `value <= -1` или `value >= 1`, результат `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Atanh(0)` | `0.0` |
| `Atanh(0.5)` | `0.5493061443340548` |
| `Atanh(-0.99)` | `-2.6466524123622457` |
| `Atanh(1.0)` | `null` |
| `Atanh(-1.0)` | `null` |
| `Atanh(1.1)` | `null` |
| `Atanh(null)` | `null` |
