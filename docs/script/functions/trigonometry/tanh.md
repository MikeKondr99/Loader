# Tanh

`Tanh` возвращает гиперболический тангенс.

## Tanh(value)

`Tanh(value)` принимает `num` и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Tanh(0)` | `0.0` |
| `Tanh(1)` | `0.7615941559557649` |
| `Tanh(-1)` | `-0.7615941559557649` |
| `Tanh(100)` | `1.0` |
| `Tanh(null)` | `null` |
