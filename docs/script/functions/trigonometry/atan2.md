# Atan2

`Atan2` возвращает арктангенс `y / x` с учетом квадранта.

## Atan2(y, x)

`Atan2(y, x)` принимает две координаты и возвращает угол в радианах.

Если любой аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Atan2(1, 1)` | `0.7853981633974483` |
| `Atan2(1, -1)` | `2.356194490192345` |
| `Atan2(-1, -1)` | `-2.356194490192345` |
| `Atan2(null, 1)` | `null` |
| `Atan2(1, null)` | `null` |
