# Asinh

`Asinh` возвращает гиперболический арксинус.

## Asinh(value)

`Asinh(value)` принимает `num` и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Asinh(0)` | `0.0` |
| `Asinh(1)` | `0.881373587019543` |
| `Asinh(-1)` | `-0.881373587019543` |
| `Asinh(null)` | `null` |
