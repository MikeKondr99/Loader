# Acos

`Acos` возвращает арккосинус.

## Acos(value)

`Acos(value)` принимает `num` в диапазоне от `-1` до `1` и возвращает угол в радианах.

Если входной аргумент равен `null`, результат тоже `null`.

Если `value` меньше `-1` или больше `1`, результат `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Acos(-1)` | `3.141592653589793` |
| `Acos(1)` | `0.0` |
| `Acos(-0.5)` | `2.0943951023931957` |
| `Acos(0.5)` | `1.0471975511965976` |
| `Acos(1.1)` | `null` |
| `Acos(999)` | `null` |
| `Acos(null)` | `null` |
