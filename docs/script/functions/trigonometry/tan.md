# Tan

`Tan` возвращает тангенс угла.

## Tan(radian)

`Tan(radian)` принимает угол в радианах и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Tan(0)` | `0.0` |
| `Tan(0.7853981633974483)` | `1.0` |
| `Tan(null)` | `null` |
