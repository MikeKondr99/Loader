# Cos

`Cos` возвращает косинус угла.

## Cos(radian)

`Cos(radian)` принимает угол в радианах и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Cos(0)` | `1.0` |
| `Cos(1.0471975511965976)` | `0.5` |
| `Cos(1.5707963267948966)` | `0.0` |
| `Cos(null)` | `null` |
