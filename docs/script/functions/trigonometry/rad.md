# Rad

`Rad` переводит градусы в радианы.

## Rad(degrees)

`Rad(degrees)` принимает угол в градусах и возвращает угол в радианах.

Функция не нормализует угол к диапазону одного круга. Например, `720` градусов превращается в `4 * Pi()`, а не в `0`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Rad(0)` | `0.0` |
| `Rad(90)` | `1.5707963267948966` |
| `Rad(180)` | `3.141592653589793` |
| `Rad(360)` | `6.283185307179586` |
| `Rad(720)` | `12.566370614359172` |
| `Rad(-90)` | `-1.5707963267948966` |
| `Rad(null)` | `null` |
