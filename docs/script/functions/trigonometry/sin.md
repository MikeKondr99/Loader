# Sin

`Sin` возвращает синус угла.

## Sin(radian)

`Sin(radian)` принимает угол в радианах и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Sin(0)` | `0.0` |
| `Sin(0.5235987755982988)` | `0.5` |
| `Sin(1.5707963267948966)` | `1.0` |
| `Sin(null)` | `null` |
