# Atan

`Atan` возвращает арктангенс.

## Atan(value)

`Atan(value)` принимает `num` и возвращает угол в радианах.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Atan(0)` | `0.0` |
| `Atan(1)` | `0.7853981633974483` |
| `Atan(null)` | `null` |
