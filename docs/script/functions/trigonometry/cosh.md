# Cosh

`Cosh` возвращает гиперболический косинус.

## Cosh(value)

`Cosh(value)` принимает `num` и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Cosh(0)` | `1.0` |
| `Cosh(1)` | `1.5430806348152437` |
| `Cosh(-1)` | `1.5430806348152437` |
| `Cosh(null)` | `null` |
