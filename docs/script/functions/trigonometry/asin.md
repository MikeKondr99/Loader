# Asin

`Asin` возвращает арксинус.

## Asin(value)

`Asin(value)` принимает `num` в диапазоне от `-1` до `1` и возвращает угол в радианах.

Если входной аргумент равен `null`, результат тоже `null`.

Если `value` меньше `-1` или больше `1`, результат `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Asin(0)` | `0.0` |
| `Asin(-0.5)` | `-0.5235987755982988` |
| `Asin(0.5)` | `0.5235987755982988` |
| `Asin(-1.0)` | `-1.5707963267948966` |
| `Asin(1.0)` | `1.5707963267948966` |
| `Asin(-1.1)` | `null` |
| `Asin(999)` | `null` |
| `Asin(null)` | `null` |
