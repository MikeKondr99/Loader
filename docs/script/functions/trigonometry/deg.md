# Deg

`Deg` переводит радианы в градусы.

## Deg(radians)

`Deg(radians)` принимает угол в радианах и возвращает угол в градусах.

Функция не нормализует угол к диапазону одного круга. Например, `4 * Pi()` превращается в `720`, а не в `0`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Deg(0)` | `0.0` |
| `Deg(1.5707963267948966)` | `90.0` |
| `Deg(3.1415926535897931)` | `180.0` |
| `Deg(6.2831853071795862)` | `360.0` |
| `Deg(12.566370614359172)` | `720.0` |
| `Deg(-1.5707963267948966)` | `-90.0` |
| `Deg(null)` | `null` |
