# Sinh

`Sinh` возвращает гиперболический синус.

## Sinh(value)

`Sinh(value)` принимает `num` и возвращает `num`.

Если входной аргумент равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Sinh(0)` | `0.0` |
| `Sinh(1)` | `1.1752011936438014` |
| `Sinh(-1)` | `-1.1752011936438014` |
| `Sinh(null)` | `null` |
