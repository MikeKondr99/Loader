# Date

`Date` преобразует значение в доменный тип `date`.

Функция нужна, когда значение должно дальше использоваться как дата или дата-время: для сравнения, сортировки, календарных вычислений, группировок и форматирования.

## Date(value)

`Date(value)` преобразует одно значение в дату.

Для `text` используется best-effort parsing: поддерживаются обычные ISO-like строки с датой и, если есть, временем.

Если строка не может быть разобрана как дата, результат будет `null`.

Для `date` значение возвращается без изменений.

Для `null` результатом будет `null`. Обычно `null` автоматически приводится к нужному типу по контексту. Явный `Date(null)` нужен только если нужно подсказать, что это именно date `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2025-03-27 21:19')` | `2025-03-27 21:19:00` |
| `'2025-03-27 21:40'.Date()` | `2025-03-27 21:40:00` |
| `Date('2025-03-27')` | `2025-03-27 00:00:00` |
| `''.EmptyIsNull().Date()` | `null` |
| `Date('bad')` | `null` |
| `'bad'.Date()` | `null` |
| `Date('2025-03-27').Date().Date()` | `2025-03-27 00:00:00` |

## Date(year)

`Date(year)` создает дату первого дня указанного года.

Месяц и день устанавливаются в `01`, время - в `00:00:00`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date(2023)` | `2023-01-01 00:00:00` |
| `Date(1970)` | `1970-01-01 00:00:00` |

## Date(year, month)

`Date(year, month)` создает дату первого дня указанного месяца.

День устанавливается в `01`, время - в `00:00:00`.

`month` должен быть валидным номером месяца `1..12`.

## Date(year, month, day)

`Date(year, month, day)` создает дату по году, месяцу и дню.

Время устанавливается в `00:00:00`.

`month` должен быть валидным номером месяца `1..12`. `day` должен быть валидным днем указанного месяца и года.

Примеры:

| Expression | Result |
| --- | --- |

## Date(value, format)

`Date(value, format)` парсит текст по Joda-style формату ClickHouse.

`format` должен быть константой:

```text
Date('2026-01-02', 'yyyy-MM-dd') // ok
Date('2026-01-02', Format)       // error
```

Если строка не соответствует формату, результат будет `null`.

Если входное значение равно `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2026-01-02', 'yyyy-MM-dd')` | `2026-01-02 00:00:00` |
| `'02.01.2026 03:04:05'.Date('dd.MM.yyyy HH:mm:ss')` | `2026-01-02 03:04:05` |
| `'02.01.2026 03:04:05 PM'.Date('dd.MM.yyyy hh:mm:ss a')` | `2026-01-02 15:04:05` |
| `'02.01.2026 03:04:05 AM'.Date('dd.MM.yyyy hh:mm:ss a')` | `2026-01-02 03:04:05` |
| `Date('02 Jan 2026', 'dd MMM yyyy')` | `2026-01-02 00:00:00` |
| `Date('02 January 2026', 'dd MMMM yyyy')` | `2026-01-02 00:00:00` |
| `Date('Friday, 02 January 2026', 'EEEE, dd MMMM yyyy')` | `2026-01-02 00:00:00` |
| `Date('2026/01/02', 'yyyy/MM/dd')` | `2026-01-02 00:00:00` |
| `Date('2026-1-2', 'yyyy-M-d')` | `2026-01-02 00:00:00` |
| `Date('2026-001', 'yyyy-DDD')` | `2026-01-01 00:00:00` |
| `Date('2026-01-02T03:04:05', 'yyyy-MM-dd\\'T\\'HH:mm:ss')` | `2026-01-02 03:04:05` |
| `Date('2026-W01-5', 'xxxx-\\'W\\'ww-e')` | `2026-01-02 00:00:00` |
| `Date('02 янв. 2026', 'dd MMM yyyy')` | `null` |
| `Date('bad', 'yyyy-MM-dd')` | `null` |
| `Date(null, 'yyyy-MM-dd')` | `null` |
