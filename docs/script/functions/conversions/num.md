# Num

`Num` преобразует значение в доменный тип `num`.

Функция нужна, когда значение должно дальше использоваться как число с дробной частью: для арифметики, агрегаций, сравнений или сортировки.

## Num(value)

`Num(value)` преобразует одно значение в число.

Для `num` значение возвращается без изменений.

Для `int` значение становится числом без изменения математического значения.

Для `text` ожидается десятичная запись с точкой как разделителем дробной части. Если строка не может быть разобрана как число, результат будет `null`.

Для `bool` значение `true` становится `1.0`, `false` становится `0.0`.

Для `null` результатом будет `null`. Обычно `null` автоматически приводится к нужному типу по контексту. Явный `Num(null)` нужен только если нужно подсказать, что это именно числовой `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Num(25)` | `25.0` |
| `Num('25')` | `25.0` |
| `Num(2.5)` | `2.5` |
| `Num(false)` | `0.0` |
| `Num(true)` | `1.0` |
| `Num(null)` | `null` |
| `Num('bad')` | `null` |
| `'bad'.Num()` | `null` |
| `Num('')` | `null` |
| `Num('12,34')` | `null` |

## Num(value, decimalSeparator)

`Num(value, decimalSeparator)` преобразует text в число с указанным десятичным разделителем.

`decimalSeparator` должен быть константой.

Если `value` не может быть разобран с указанным разделителем, результат будет `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Num('12,34', ',')` | `12.34` |
| `'12,34'.Num(',')` | `12.34` |
| `Num('12.34', '.')` | `12.34` |
| `'1 234,56'.Replace(' ', '').Num(',')` | `1234.56` |
| `Num('1,234.56', '.')` | `null` |
| `Num('bad', ',')` | `null` |
| `Num('', ',')` | `null` |
| `Num(null, ',')` | `null` |

## Edge cases

`decimalSeparator` задает только символ дробной части. Он не включает правила тысячных разделителей.

Если в строке есть пробелы или separators групп, их нужно удалить до `Num`.
