# Bool

`Bool` преобразует значение в доменный тип `bool`.

Функция нужна, когда значение должно дальше использоваться как логическое условие: в `WHERE`, `If`, boolean expressions или как boolean field.

## Bool(value)

`Bool(value)` преобразует одно значение в boolean.

Для `bool` значение возвращается без изменений.

Для `text` результат `false` получается только из пустой строки. Любая непустая строка становится `true`.

Для `int` и `num` результат `true` получается, если число больше `0`. Ноль и отрицательные числа становятся `false`.

Для `null` результатом будет `null`. В условии `If` или `WHERE` такой `null` не считается `true`.

Примеры:

| Expression | Result |
| --- | --- |
| `Bool(25)` | `true` |
| `Bool(0)` | `false` |
| `Bool(-5)` | `false` |
| `Bool(23)` | `true` |
| `Bool(0.0)` | `false` |
| `Bool(-5.0)` | `false` |
| `Bool(23.0)` | `true` |
| `Bool('25')` | `true` |
| `Bool('bad')` | `true` |
| `Bool('')` | `false` |
| `Bool(false)` | `false` |
| `Bool(true)` | `true` |
| `If(Bool(null), 'then', 'else')` | `'else'` |

## Edge cases

`Bool('false')` не является специальным текстовым значением в этой функции. Так как строка непустая, она будет приведена к `true`.

Если нужно разбирать текстовые значения `'true'`, `'false'`, `'1'`, `'0'`, нужно использовать функцию, которая явно предназначена для такого формата, например JSON bool parsing в JSON functions.
