# Int

`Int` преобразует значение в доменный тип `int`.

Функция нужна, когда значение должно дальше использоваться как целое число: для сравнения, сортировки, агрегаций, вычислений или ключей.

## Int(value)

`Int(value)` преобразует одно значение в целое число.

Для `int` значение возвращается без изменений.

Для `text` ожидается строка с целым числом. Если строка не может быть разобрана как целое число, результат будет `null`.

Для `num` дробная часть отбрасывается приведением к целому числу.

Для `bool` значение `true` становится `1`, `false` становится `0`.

Для `null` результатом будет `null`. Обычно `null` автоматически приводится к нужному типу по контексту. Явный `Int(null)` нужен только если нужно подсказать, что это именно целочисленный `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Int(25)` | `25` |
| `Int('25')` | `25` |
| `Int(2.6)` | `2` |
| `Int(false)` | `0` |
| `Int(true)` | `1` |
| `Int(null)` | `null` |
| `Int('bad')` | `null` |
| `'bad'.Int()` | `null` |
| `Int('')` | `null` |
| `Int('12,34')` | `null` |

## Edge cases

`Int` не учитывает локальные форматы чисел. Строка `12,34` не считается целым числом.

Если нужно сначала убрать пробелы, заменить разделители или очистить текст, это нужно сделать отдельными string functions перед `Int`.

```text
'1 234'.Replace(' ', '').Int()
```
