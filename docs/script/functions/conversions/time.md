# Time

`Time` преобразует значение в доменный тип `time`.

Функция нужна, когда значение должно дальше использоваться как время суток без самостоятельной даты: для сравнения, группировки, выделения часа/минуты/секунды или форматирования.

## Time(value)

`Time(value)` парсит текст как время в формате `HH:mm:ss`.

Если `value` имеет тип `date`, `Time(value)` извлекает время суток и отбрасывает дату.

Если строка не соответствует формату или содержит невалидное время, результат будет `null`.

Для `null` результатом будет `null`. Обычно `null` автоматически приводится к нужному типу по контексту. Явный `Time(null)` нужен только если нужно подсказать, что это именно time `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Time('03:04:05')` | `03:04:05` |
| `Time(Date('2026-08-30 12:34:56'))` | `12:34:56` |
| `'23:59:59'.Time()` | `23:59:59` |
| `Time('bad')` | `null` |
| `Time('03:04')` | `null` |
| `Time('24:00:00')` | `null` |
| `Time('25:00:00')` | `null` |
| `Time(null)` | `null` |

## Time(value, format)

`Time(value, format)` парсит текст как время по Joda-style формату ClickHouse.

`format` должен быть константой:

```text
Time('03.04.05', 'HH.mm.ss') // ok
Time('03.04.05', Format)     // error
```

Формат считается time-only форматом. Даже если во входе есть дата, логическое значение `time` сохраняет только время суток.

Если строка не соответствует формату или содержит невалидное время, результат будет `null`.

Если входное значение равно `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Time('03.04.05', 'HH.mm.ss')` | `03:04:05` |
| `'03:04:05 PM'.Time('hh:mm:ss a')` | `15:04:05` |
| `'13:04:05 PM'.Time('hh:mm:ss a')` | `null` |
| `'18 PM'.Time('hh a')` | `null` |
| `Time('2026-01-02 03:04:05', 'yyyy-MM-dd HH:mm:ss')` | `03:04:05` |
| `Time('2026-01-02', 'yyyy-MM-dd')` | `00:00:00` |
| `Time('bad', 'HH.mm.ss')` | `null` |
| `Time(null, 'HH.mm.ss')` | `null` |

## Time(hour, minute)

`Time(hour, minute)` создает время по часу и минуте.

Секунды устанавливаются в `0`.

Час должен быть в диапазоне `0..23`, минута - в диапазоне `0..59`. Если компоненты вне диапазона, результат будет `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Time(3, 4)` | `03:04:00` |

## Time(hour, minute, second)

`Time(hour, minute, second)` создает время по часу, минуте и секунде.

Час должен быть в диапазоне `0..23`, минута и секунда - в диапазоне `0..59`. Если компоненты вне диапазона, результат будет `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Time(3, 4, 5)` | `03:04:05` |
| `Time(23, 59, 59)` | `23:59:59` |
| `Time(24, 0, 0)` | `null` |
| `Time(3, 60, 0)` | `null` |
| `Time(3, 4, 60)` | `null` |
| `Time(null, 4, 5)` | `null` |
