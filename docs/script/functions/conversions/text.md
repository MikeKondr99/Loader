# Text

`Text` преобразует значение в доменный тип `text`.

Функция нужна, когда значение должно дальше обрабатываться как строка: выводиться, склеиваться с другим текстом, использоваться как строковый ключ или форматироваться из даты/времени.

## Text(value)

`Text(value)` преобразует одно значение в строку.

Для `text` значение возвращается без изменений.

Для `int` используется десятичная запись без разделителей групп:

```text
Text(25000000) -> '25000000'
```

Для `num` используется десятичная запись с точкой как разделителем дробной части:

```text
Text(2.5) -> '2.5'
Text(1000000.123) -> '1000000.123'
```

Для `bool` результатом будет строка `'true'` или `'false'` в нижнем регистре.

Для `date` без формата используется вид:

```text
yyyy-MM-dd HH:mm:ss
```

Для `time` без формата используется вид:

```text
HH:mm:ss
```

Для `null` результатом будет `null`. Обычно `null` автоматически приводится к нужному типу по контексту. Явный `Text(null)` нужен только если нужно подсказать, что это именно текстовый `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Text(25)` | `'25'` |
| `Text(25000000)` | `'25000000'` |
| `Text('25')` | `'25'` |
| `Text(2.5)` | `'2.5'` |
| `Text(1000000.123)` | `'1000000.123'` |
| `Text(false)` | `'false'` |
| `Text(true)` | `'true'` |
| `Text(null)` | `null` |

## Text(date, format)

`Text(date, format)` форматирует дату по Joda-style формату ClickHouse.

`format` должен быть константой:

```text
Date('2026-01-02').Text('yyyy-MM-dd') // ok
Date('2026-01-02').Text(Format)       // error
```

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2025-03-27 21:19').Text()` | `'2025-03-27 21:19:00'` |
| `Date('2025-03-27').Text()` | `'2025-03-27 00:00:00'` |
| `Date('2026-01-02 15:04:05').Text('yyyy-MM-dd')` | `'2026-01-02'` |
| `Date('2026-01-02 15:04:05').Text('dd.MM.yyyy hh:mm:ss a')` | `'02.01.2026 03:04:05 PM'` |
| `Date('2026-01-02 15:04:05').Text('dd MMMM yyyy')` | `'02 January 2026'` |
| `Date('2026-01-02', 'yyyy-MM-dd').DateOnly().Text('dd MMM yyyy')` | `'02 Jan 2026'` |
| `Date('2026-01-02', 'yyyy-MM-dd').DateOnly().Text('yyyy-MM-dd')` | `'2026-01-02'` |
| `Date(null, 'yyyy-MM-dd').DateOnly().Text('yyyy-MM-dd')` | `null` |

## Text(time, format)

`Text(time, format)` форматирует время по Joda-style формату ClickHouse.

`format` должен быть константой.

Логический `time` внутри DWH представлен как время на базовой дате `1970-01-01`. Поэтому если в формате запросить дату, она будет видна:

```text
Time('18:00:00').Text('yyyy-MM-dd HH:mm:ss') -> '1970-01-01 18:00:00'
```

Если входное время равно `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Time('03:04:05').Text()` | `'03:04:05'` |
| `Time('15:04:05').Text('hh:mm:ss a')` | `'03:04:05 PM'` |
| `Time('18:00:00').Text('hh a')` | `'06 PM'` |
| `Time('18:00:00').Text('yyyy-MM-dd HH:mm:ss')` | `'1970-01-01 18:00:00'` |
| `Time(null).Text()` | `null` |
