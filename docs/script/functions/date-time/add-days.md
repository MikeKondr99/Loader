# AddDays

`AddDays` сдвигает `date` на указанное количество дней.

## AddDays(date, days)

`AddDays(date, days)` возвращает дату, полученную добавлением `days` к исходной дате.

`days` может быть отрицательным. Время внутри даты сохраняется.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-01-01').AddDays(1)` | `2023-01-02 00:00:00` |
| `Date('2023-01-01 08:30').AddDays(1)` | `2023-01-02 08:30:00` |
| `Date('2023-12-31').AddDays(1)` | `2024-01-01 00:00:00` |
| `Date('2024-02-28').AddDays(1)` | `2024-02-29 00:00:00` |
| `Date('2023-01-01').AddDays(-1)` | `2022-12-31 00:00:00` |
| `Date(null).AddDays(1)` | `null` |
| `Date('2023-01-01').AddDays(null)` | `null` |
