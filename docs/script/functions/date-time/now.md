# Now

`Now` возвращает текущую дату и время.

## Now()

`Now()` возвращает текущий timestamp на стороне выполнения запроса.

Значение зависит от момента выполнения запроса, поэтому в документации не фиксируется конкретная дата.

Примеры:

| Expression | Result |
| --- | --- |
| `Now().Year() >= 1970` | `true` |
