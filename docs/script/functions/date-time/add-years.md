# AddYears

`AddYears` сдвигает `date` на указанное количество лет.

## AddYears(date, years)

`AddYears(date, years)` возвращает дату, полученную добавлением `years` к исходной дате.

`years` может быть отрицательным. Время внутри даты сохраняется.

Если целевая дата невозможна, например 29 февраля в невисокосном году, дата нормализуется на последний валидный день месяца.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-02-15').AddYears(1)` | `2024-02-15 00:00:00` |
| `Date('2024-02-29').AddYears(1)` | `2025-02-28 00:00:00` |
| `Date('2023-02-15 18:20').AddYears(1)` | `2024-02-15 18:20:00` |
| `Date('2023-02-15').AddYears(-1)` | `2022-02-15 00:00:00` |
| `Date(null).AddYears(1)` | `null` |
| `Date('2023-02-15').AddYears(null)` | `null` |
