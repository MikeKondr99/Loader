# AddMonths

`AddMonths` сдвигает `date` на указанное количество месяцев.

## AddMonths(date, months)

`AddMonths(date, months)` возвращает дату, полученную добавлением `months` к исходной дате.

`months` может быть отрицательным. Время внутри даты сохраняется.

Если в целевом месяце нет исходного дня, дата нормализуется на последний валидный день месяца.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-01-15').AddMonths(1)` | `2023-02-15 00:00:00` |
| `Date('2023-01-31').AddMonths(1)` | `2023-02-28 00:00:00` |
| `Date('2024-01-31').AddMonths(1)` | `2024-02-29 00:00:00` |
| `Date('2023-12-15').AddMonths(1)` | `2024-01-15 00:00:00` |
| `Date('2023-01-15').AddMonths(-1)` | `2022-12-15 00:00:00` |
| `Date(null).AddMonths(1)` | `null` |
| `Date('2023-01-15').AddMonths(null)` | `null` |
