# YearWeek

`YearWeek` возвращает ISO-год и ISO-неделю из `date`.

## YearWeek(date)

`YearWeek(date)` возвращает текст в формате `YYYY-WNN`.

ISO-год может отличаться от календарного года даты в первые и последние дни года.
Это происходит потому, что ISO-неделя начинается с понедельника, а первой неделей ISO-года считается неделя, в которой есть первый четверг года.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-01-02').YearWeek()` | `'2023-W01'` |
| `Date('2023-01-01').YearWeek()` | `'2022-W52'` |
| `Date('2020-12-31').YearWeek()` | `'2020-W53'` |
| `Date(null).YearWeek()` | `null` |
