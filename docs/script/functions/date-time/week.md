# Week

`Week` возвращает ISO-номер недели из `date`.

## Week(date)

`Week(date)` возвращает ISO-номер недели в году.

ISO-неделя начинается с понедельника. Первой неделей ISO-года считается неделя, в которой есть первый четверг года. Поэтому первые дни января могут относиться к последней ISO-неделе предыдущего года.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-01-02').Week()` | `1` |
| `Date('2023-01-01').Week()` | `52` |
| `Date('2020-12-31').Week()` | `53` |
| `Date(null).Week()` | `null` |
