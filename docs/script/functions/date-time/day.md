# Day

`Day` возвращает день месяца из `date`.

## Day(date)

`Day(date)` возвращает день месяца.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-05-15').Day()` | `15` |
| `Date('2024-02-29').Day()` | `29` |
| `Date('2023-01-01').Day()` | `1` |
| `Date('2023-12-31').Day()` | `31` |
| `Date(null).Day()` | `null` |
