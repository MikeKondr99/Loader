# Year

`Year` возвращает год из `date`.

## Year(date)

`Year(date)` возвращает календарный год.

Если входная дата равна `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Date('2023-05-15').Year()` | `2023` |
| `Date('2024-02-29 14:30:22').Year()` | `2024` |
| `Date('1999-12-31 23:59:59').Year()` | `1999` |
| `Date(null).Year()` | `null` |
