# SUM

`SUM` считает сумму числовых значений внутри группы.

## SUM(value)

`SUM(value)` поддерживает `int` и `num`.

`null` значения игнорируются.

Если в группе нет строк или все значения отфильтрованы, результат `0`.

Результат имеет тот же доменный тип, что и входное поле.

## Пример

```ts
Заказы:
LOAD *
FROM Inline(
  Покупатель, Продажи, Выручка;
  'Альфа', 10, 100.5;
  'Альфа', 18, 180.25;
  'Альфа', null, null;
  'Бета', 4, 40.0;
  'Бета', 5, 50.0;
  'Гамма', null, null
);

Итог:
LOAD
  Покупатель,
  SUM(Продажи) AS ВсегоПродаж,
  SUM(Выручка) AS ВсегоВыручка
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ВсегоПродаж | ВсегоВыручка |
| --- | ---: | ---: |
| Альфа | 28 | 280.75 |
| Бета | 9 | 90.0 |
| Гамма | 0 | 0 |

Если после фильтрации группа пустая, `SUM` возвращает `0`.
