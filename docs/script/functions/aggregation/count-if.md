# COUNT_IF

`COUNT_IF` считает строки внутри группы, для которых boolean-выражение истинно.

## COUNT_IF(condition)

`COUNT_IF(condition)` принимает `bool` и возвращает `int`.

`true` увеличивает счетчик, `false` и `null` не увеличивают счетчик.

Если строк нет или ни одна строка не дала `true`, результат `0`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Оплачен
FROM Inline(
  Покупатель, Оплачен;
  'Альфа', true;
  'Альфа', false;
  'Альфа', null;
  'Бета', true;
  'Бета', true
);

Итог:
LOAD
  Покупатель,
  COUNT_IF(Оплачен) AS ОплаченныхЗаказов
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ОплаченныхЗаказов |
| --- | ---: |
| Альфа | 1 |
| Бета | 2 |
