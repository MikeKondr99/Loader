# CORREL

`CORREL` считает коэффициент корреляции Пирсона между двумя числовыми выражениями внутри группы.

## CORREL(left, right)

`CORREL(left, right)` принимает `int` или `num` в обоих аргументах и возвращает `num`.

`num` аргументы перед расчетом приводятся к `Float64`, поэтому функция работает и с decimal-значениями, полученными через `Num(text)`. Для пары `int, int` лишнее приведение не добавляется.

`null` значения игнорируются: строка участвует в расчете только если оба аргумента не `null`.

Если корреляцию нельзя посчитать, результат `null`.

## Пример

```ts
Наблюдения:
LOAD
  Группа,
  Реклама,
  Выручка
FROM Inline(
  Группа, Реклама, Выручка;
  'Альфа', 1, 2;
  'Альфа', 2, 4;
  'Альфа', 3, 6;
  'Альфа', 4, 8;
  'Бета', 1, null;
  'Бета', null, 4
);

Итог:
LOAD
  Группа,
  CORREL(Реклама, Выручка) AS Корреляция
FROM Наблюдения
GROUP BY Группа
ORDER BY Группа;
```

Результат:

| Группа | Корреляция |
| --- | ---: |
| Альфа | 1 |
| Бета | null |
