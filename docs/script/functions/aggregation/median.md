# MEDIAN

`MEDIAN` возвращает медиану numeric значений внутри группы.

## MEDIAN(value)

`MEDIAN(value)` принимает `num`.

`null` значения игнорируются.

## Пример

```ts
Заказы:
LOAD *
FROM Inline(
  Покупатель, Выручка;
  'Альфа', 1.0;
  'Альфа', 2.0;
  'Альфа', 3.0;
  'Альфа', 4.0;
  'Бета', 10.0;
  'Бета', null;
  'Бета', 30.0
);

Итог:
LOAD
  Покупатель,
  MEDIAN(Выручка) AS МедианнаяВыручка
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | МедианнаяВыручка |
| --- | ---: |
| Альфа | 2.5 |
| Бета | 20.0 |
