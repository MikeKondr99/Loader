# COUNT_DISTINCT

`COUNT_DISTINCT` считает уникальные non-null значения внутри группы.

## COUNT_DISTINCT(value)

`COUNT_DISTINCT(value)` поддерживает `text`, `int`, `num`, `date` и `time`.

`null` не учитывается.

Результат всегда `int!`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  НомерЗаказа,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа,
  ВремяЗаказа.Time() AS ВремяЗаказа
FROM Inline(
  Покупатель, Товар, НомерЗаказа, Выручка, ДатаЗаказа, ВремяЗаказа;
  'Альфа', 'Чай', 1, 100.5, '2023-01-01 00:00:00', '10:00:00';
  'Альфа', 'Чай', 7, 100.5, '2023-01-02 00:00:00', '10:00:00';
  'Альфа', 'Кофе', 1, 90.25, '2023-01-01 00:00:00', '08:30:00';
  'Альфа', null, null, null, null, null;
  'Бета', 'Чай', 5, 40.0, '2023-02-10 12:00:00', '12:00:00';
  'Бета', 'Кофе', 2, 30.5, '2023-02-10 12:00:00', '09:15:00';
  'Бета', 'Чай', 5, 40.0, '2023-02-11 12:00:00', '12:00:00'
);

Итог:
LOAD
  Покупатель,
  COUNT_DISTINCT(Товар) AS Товаров,
  COUNT_DISTINCT(НомерЗаказа) AS НомеровЗаказа,
  COUNT_DISTINCT(Выручка) AS Выручек,
  COUNT_DISTINCT(ДатаЗаказа) AS ДатЗаказа,
  COUNT_DISTINCT(ВремяЗаказа) AS ВременЗаказа
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | Товаров | НомеровЗаказа | Выручек | ДатЗаказа | ВременЗаказа |
| --- | ---: | ---: | ---: | ---: | ---: |
| Альфа | 2 | 2 | 2 | 2 | 2 |
| Бета | 2 | 2 | 2 | 2 | 2 |
