# CONCAT

`CONCAT` склеивает text значения внутри группы.

Это aggregate function, не то же самое, что строковый оператор `+`.

## CONCAT(value)

`CONCAT(value)` склеивает non-null text значения без delimiter.

Если non-null значений нет, результат `null`.

## CONCAT(value, delimiter)

`CONCAT(value, delimiter)` склеивает non-null text значения с delimiter.

Если `delimiter` равен `null`, результат зависит от ClickHouse `arrayStringConcat`.

## CONCAT(value, delimiter, sort)

`CONCAT(value, delimiter, sort)` сначала сортирует значения по `sort`, а затем склеивает `value`.

`sort` может иметь тип `text`, `int`, `num`, `date` или `time`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  ПорядокInt,
  ПорядокNum,
  ПорядокДата.Date() AS ПорядокДата,
  ПорядокВремя.Time() AS ПорядокВремя,
  ПорядокТекст
FROM Inline(
  Покупатель, Товар, ПорядокInt, ПорядокNum, ПорядокДата, ПорядокВремя, ПорядокТекст;
  'Альфа', 'А', 2, 2.5, '2023-01-02 00:00:00', '10:00:00', 'б';
  'Альфа', null, 3, 3.5, '2023-01-03 00:00:00', '11:00:00', 'в';
  'Альфа', 'Б', 1, 1.5, '2023-01-01 00:00:00', '08:30:00', 'а';
  'Альфа', 'В', 4, 4.5, '2023-01-04 00:00:00', '12:00:00', 'г';
  'Бета', 'X', 2, 2.5, '2023-02-02 00:00:00', '12:00:00', 'б';
  'Бета', 'Y', 1, 1.5, '2023-02-01 00:00:00', '09:15:00', 'а';
  'Гамма', null, 1, 1.5, '2023-03-01 00:00:00', '09:00:00', 'а'
);

Итог:
LOAD
  Покупатель,
  CONCAT(Товар) AS БезРазделителя,
  CONCAT(Товар, '|') AS СРазделителем,
  CONCAT(Товар, '|', ПорядокInt) AS ПоInt,
  CONCAT(Товар, '|', ПорядокNum) AS ПоNum,
  CONCAT(Товар, '|', ПорядокДата) AS ПоДате,
  CONCAT(Товар, '|', ПорядокВремя) AS ПоВремени,
  CONCAT(Товар, '|', ПорядокТекст) AS ПоТексту
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | БезРазделителя | СРазделителем | ПоInt | ПоNum | ПоДате | ПоВремени | ПоТексту |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Альфа | АБВ | А\|Б\|В | Б\|А\|В | Б\|А\|В | Б\|А\|В | Б\|А\|В | Б\|А\|В |
| Бета | XY | X\|Y | Y\|X | Y\|X | Y\|X | Y\|X | Y\|X |
| Гамма | null | null | null | null | null | null | null |
