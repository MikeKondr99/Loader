# AVG

`AVG` считает среднее значение внутри группы.

## AVG(value)

`AVG(value)` поддерживает `int`, `num` и `date`.

Для `int` и `num` результат имеет тип `num`.

Для `date` результат имеет тип `date`. Средняя дата считается через Unix timestamp с точностью до секунды.

`null` значения игнорируются.

Если в группе нет non-null значений, результат `null`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Продажи,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа
FROM Inline(
  Покупатель, Продажи, Выручка, ДатаЗаказа;
  'Альфа', 10, 100.5, '2023-01-01 00:00:00';
  'Альфа', 18, 180.25, '2023-01-03 00:00:00';
  'Альфа', null, null, null;
  'Бета', 4, 40.0, '2023-01-10 12:00:00';
  'Бета', 5, 50.0, '2023-01-10 14:00:00'
);

Итог:
LOAD
  Покупатель,
  AVG(Продажи) AS СредниеПродажи,
  AVG(Выручка) AS СредняяВыручка,
  AVG(ДатаЗаказа) AS СредняяДата
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | СредниеПродажи | СредняяВыручка | СредняяДата |
| --- | ---: | ---: | --- |
| Альфа | 14.0 | 140.375 | 2023-01-02 00:00:00 |
| Бета | 4.5 | 45.0 | 2023-01-10 13:00:00 |

Если после фильтрации нет non-null значений, `AVG` возвращает `null`.
