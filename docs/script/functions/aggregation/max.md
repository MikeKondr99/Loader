# MAX

`MAX` возвращает максимальное non-null значение внутри группы.

## MAX(value)

`MAX(value)` поддерживает `text`, `int`, `num`, `date` и `time`.

Если в группе нет non-null значений, результат `null`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  Продажи,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа,
  ВремяЗаказа.Time() AS ВремяЗаказа
FROM Inline(
  Покупатель, Товар, Продажи, Выручка, ДатаЗаказа, ВремяЗаказа;
  'Альфа', 'Банан', 5, 100.5, '2023-01-03 10:00:00', '10:00:00';
  'Альфа', 'Апельсин', null, 90.25, '2023-01-01 12:00:00', '08:30:00';
  'Альфа', 'Яблоко', 8, null, null, null;
  'Бета', 'Чай', 4, 40.0, '2023-02-10 12:00:00', '12:00:00';
  'Бета', 'Кофе', 5, 30.5, '2023-02-09 14:00:00', '09:15:00';
  'Гамма', null, null, null, null, null
);

Итог:
LOAD
  Покупатель,
  MAX(Товар) AS ПоследнийТовар,
  MAX(Продажи) AS МаксПродажи,
  MAX(Выручка) AS МаксВыручка,
  MAX(ДатаЗаказа) AS МаксДата,
  MAX(ВремяЗаказа) AS МаксВремя
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ПоследнийТовар | МаксПродажи | МаксВыручка | МаксДата | МаксВремя |
| --- | --- | ---: | ---: | --- | --- |
| Альфа | Яблоко | 8 | 100.5 | 2023-01-03 10:00:00 | 10:00:00 |
| Бета | Чай | 5 | 40.0 | 2023-02-10 12:00:00 | 12:00:00 |
| Гамма | null | null | null | null | null |
