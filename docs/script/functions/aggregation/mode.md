# MODE

`MODE` возвращает наиболее часто встречающееся non-null значение внутри группы.

## MODE(value)

`MODE(value)` поддерживает `text`, `int`, `num`, `date` и `time`.

`null` значения игнорируются.

Если non-null значений нет, результат `null`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  Продажи,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа,
  ВремяЗаказа.Time() AS ВремяЗаказа
FROM Inline(
  Покупатель, Товар, Продажи, Выручка, ДатаЗаказа, ВремяЗаказа;
  'Альфа', 'Чай', 10, 100.5, '2023-01-01 00:00:00', '10:00:00';
  'Альфа', 'Кофе', 10, 100.5, '2023-01-01 00:00:00', '10:00:00';
  'Альфа', 'Чай', 18, 90.25, '2023-01-03 00:00:00', '08:30:00';
  'Альфа', null, null, null, null, null;
  'Бета', 'Чай', 4, 40.0, '2023-02-10 12:00:00', '12:00:00';
  'Бета', 'Кофе', 5, 30.5, '2023-02-09 14:00:00', '09:15:00';
  'Бета', 'Кофе', 5, 30.5, '2023-02-09 14:00:00', '09:15:00';
  'Гамма', null, null, null, null, null
);

Итог:
LOAD
  Покупатель,
  MODE(Товар) AS ЧастыйТовар,
  MODE(Продажи) AS ЧастыеПродажи,
  MODE(Выручка) AS ЧастаяВыручка,
  MODE(ДатаЗаказа) AS ЧастаяДата,
  MODE(ВремяЗаказа) AS ЧастоеВремя
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ЧастыйТовар | ЧастыеПродажи | ЧастаяВыручка | ЧастаяДата | ЧастоеВремя |
| --- | --- | ---: | ---: | --- | --- |
| Альфа | Чай | 10 | 100.5 | 2023-01-01 00:00:00 | 10:00:00 |
| Бета | Кофе | 5 | 30.5 | 2023-02-09 14:00:00 | 09:15:00 |
| Гамма | null | null | null | null | null |
