# FRACTILE

`FRACTILE` возвращает непрерывную включительную квантиль числовых значений внутри группы.

## FRACTILE(value, p)

`FRACTILE(value, p)` принимает `int` или `num` и использует непрерывную включительную квантиль.

`p` должен быть константой в диапазоне `0..1`.

`null` значения игнорируются.

## Пример

```ts
Заказы:
LOAD *
FROM Inline(
  Покупатель, Выручка;
  'Альфа', 1.0;
  'Альфа', 2.0;
  'Альфа', 3.0;
  'Альфа', 4.0;
  'Бета', 1.0;
  'Бета', null;
  'Бета', 2.0;
  'Бета', 3.0;
  'Бета', 4.0
);

Итог:
LOAD
  Покупатель,
  FRACTILE(Выручка, 0.25) AS Квартиль25,
  FRACTILE(Выручка, 0.5) AS Квартиль50,
  FRACTILE(Выручка, 0.75) AS Квартиль75
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | Квартиль25 | Квартиль50 | Квартиль75 |
| --- | ---: | ---: | ---: |
| Альфа | 1.75 | 2.5 | 3.25 |
| Бета | 1.75 | 2.5 | 3.25 |

`FRACTILE(Выручка, p)` завершится ошибкой resolution, потому что `p` должен быть константой, а не полем.

`FRACTILE(Выручка, -0.1)` и `FRACTILE(Выручка, 1.1)` завершатся ошибкой resolution, потому что `p` выходит за диапазон `0..1`.
