# COUNT

`COUNT` считает строки или значения внутри группы.

## COUNT()

`COUNT()` возвращает количество строк в группе.

Строки, где поля равны `null`, тоже считаются.

Результат всегда `int!`.

## COUNT(value)

`COUNT(value)` возвращает количество non-null значений.

Результат всегда `int!`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  НомерЗаказа,
  Продажи,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа,
  ВремяЗаказа.Time() AS ВремяЗаказа
FROM Inline(
  Покупатель, Товар, НомерЗаказа, Продажи, Выручка, ДатаЗаказа, ВремяЗаказа;
  'Альфа', 'Чай', 1, 10, 100.5, '2023-01-01 00:00:00', '10:00:00';
  'Альфа', 'Чай', 7, 18, 180.25, '2023-01-02 00:00:00', '08:30:00';
  'Альфа', null, 4, null, null, null, null;
  'Бета', 'Чай', 5, 4, 40.0, '2023-02-10 12:00:00', '12:00:00';
  'Бета', 'Кофе', 2, 5, 50.0, '2023-02-09 14:00:00', '09:15:00';
  'Гамма', null, null, null, null, null, null
);

Итог:
LOAD
  Покупатель,
  COUNT() AS ВсегоСтрок,
  COUNT(Товар) AS Товаров,
  COUNT(НомерЗаказа) AS НомеровЗаказа,
  COUNT(Продажи) AS Продаж,
  COUNT(Выручка) AS Выручек,
  COUNT(ДатаЗаказа) AS ДатЗаказа,
  COUNT(ВремяЗаказа) AS ВременЗаказа
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ВсегоСтрок | Товаров | НомеровЗаказа | Продаж | Выручек | ДатЗаказа | ВременЗаказа |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Альфа | 3 | 2 | 3 | 2 | 2 | 2 | 2 |
| Бета | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
| Гамма | 1 | 0 | 0 | 0 | 0 | 0 | 0 |
