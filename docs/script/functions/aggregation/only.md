# ONLY

`ONLY` возвращает значение, если внутри группы есть ровно одно уникальное значение.

## ONLY(value)

`ONLY(value)` поддерживает `text`, `int`, `num`, `date` и `time`.

`null` считается отдельным значением.

Если вместе с обычным значением встречается `null`, результат будет `null`.
Если все значения в группе равны `null`, результат тоже будет `null`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  КодПокупателя,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа,
  ВремяЗаказа.Time() AS ВремяЗаказа
FROM Inline(
  Покупатель, Товар, КодПокупателя, Выручка, ДатаЗаказа, ВремяЗаказа;
  'Альфа', 'Чай', 1, 100.5, '2023-01-01 00:00:00', '10:00:00';
  'Альфа', 'Чай', 1, 100.5, '2023-01-01 00:00:00', '10:00:00';
  'Альфа', null, 1, null, null, null;
  'Бета', 'Чай', 2, 40.0, '2023-02-10 12:00:00', '12:00:00';
  'Бета', 'Кофе', 2, 30.5, '2023-02-11 12:00:00', '09:15:00';
  'Гамма', null, null, null, null, null
);

Итог:
LOAD
  Покупатель,
  ONLY(Товар) AS ЕдинственныйТовар,
  ONLY(КодПокупателя) AS ЕдинственныйКод,
  ONLY(Выручка) AS ЕдинственнаяВыручка,
  ONLY(ДатаЗаказа) AS ЕдинственнаяДата,
  ONLY(ВремяЗаказа) AS ЕдинственноеВремя
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ЕдинственныйТовар | ЕдинственныйКод | ЕдинственнаяВыручка | ЕдинственнаяДата | ЕдинственноеВремя |
| --- | --- | ---: | ---: | --- | --- |
| Альфа | null | 1 | null | null | null |
| Бета | null | 2 | null | null | null |
| Гамма | null | null | null | null | null |
