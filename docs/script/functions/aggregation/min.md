# MIN

`MIN` возвращает минимальное non-null значение внутри группы.

## MIN(value)

`MIN(value)` поддерживает `text`, `int`, `num`, `date` и `time`.

Если в группе нет non-null значений, результат `null`.

## Пример

```ts
Заказы:
LOAD
  Покупатель,
  Товар,
  Продажи,
  Выручка,
  ДатаЗаказа.Date() AS ДатаЗаказа,
  ВремяЗаказа.Time() AS ВремяЗаказа
FROM Inline(
  Покупатель, Товар, Продажи, Выручка, ДатаЗаказа, ВремяЗаказа;
  'Альфа', 'Банан', 5, 100.5, '2023-01-03 10:00:00', '10:00:00';
  'Альфа', 'Апельсин', null, 90.25, '2023-01-01 12:00:00', '08:30:00';
  'Альфа', 'Яблоко', 8, null, null, null;
  'Бета', 'Чай', 4, 40.0, '2023-02-10 12:00:00', '12:00:00';
  'Бета', 'Кофе', 5, 30.5, '2023-02-09 14:00:00', '09:15:00';
  'Гамма', null, null, null, null, null
);

Итог:
LOAD
  Покупатель,
  MIN(Товар) AS ПервыйТовар,
  MIN(Продажи) AS МинПродажи,
  MIN(Выручка) AS МинВыручка,
  MIN(ДатаЗаказа) AS МинДата,
  MIN(ВремяЗаказа) AS МинВремя
FROM Заказы
GROUP BY Покупатель
ORDER BY Покупатель;
```

Результат:

| Покупатель | ПервыйТовар | МинПродажи | МинВыручка | МинДата | МинВремя |
| --- | --- | ---: | ---: | --- | --- |
| Альфа | Апельсин | 5 | 90.25 | 2023-01-01 12:00:00 | 08:30:00 |
| Бета | Кофе | 4 | 30.5 | 2023-02-09 14:00:00 | 09:15:00 |
| Гамма | null | null | null | null | null |
