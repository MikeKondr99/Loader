# STDDEV

`STDDEV` считает стандартное отклонение внутри группы.

## STDDEV(value)

`STDDEV(value)` принимает `int` или `num` и возвращает `num`.

Функция использует population standard deviation: отклонение считается по всей группе, а не по выборке.

`null` значения игнорируются.

Decimal-значения, полученные через `Num(text)`, поддерживаются.

Если в группе нет non-null значений, результат `null`.

## Пример

```ts test
Продажи:
LOAD
  Регион,
  Выручка
FROM Inline(
  Регион, Выручка;
  'Север', 2;
  'Север', 4;
  'Север', 4;
  'Север', 4;
  'Север', 5;
  'Север', 5;
  'Север', 7;
  'Север', 9;
  'Юг', null
);

Итог:
LOAD
  Регион,
  STDDEV(Выручка) AS Отклонение
FROM Продажи
GROUP BY Регион
ORDER BY Регион;

```

Результат:

| Регион | Отклонение |
| --- | ---: |
| Север | 2 |
| Юг | null |
