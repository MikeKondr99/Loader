# Arithmetic

Arithmetic operators выполняют базовые числовые операции.

## left + right

`+` складывает два числа.

Если оба аргумента `int`, результат `int`. Если хотя бы один аргумент `num`, результат `num`.

Если один из аргументов `null`, результат `null`, а nullability результата сохраняет тип второго аргумента.

Примеры:

| Expression | Result |
| --- | --- |
| `2 + 2` | `4` |
| `2.5 + 3.5` | `6.0` |
| `2.5 + 4` | `6.5` |
| `Type(3 + 3)` | `'int!'` |
| `2 + null` | `null` |
| `Type(2 + null)` | `'int'` |

## left - right

`-` вычитает правое число из левого.

Примеры:

| Expression | Result |
| --- | --- |
| `3 - 8` | `-5` |
| `3.0 - 8.5` | `-5.5` |

## -value

Unary `-` меняет знак числа.

Примеры:

| Expression | Result |
| --- | --- |
| `-4` | `-4` |
| `-3.0` | `-3.0` |
| `-0.0` | `0.0` |
| `-0` | `0` |

## left * right

`*` умножает два числа.

Примеры:

| Expression | Result |
| --- | --- |
| `-4.0 * 8.0` | `-32.0` |
| `-8 * -3` | `24` |

## left / right

`/` делит левое число на правое.

Оператор `/` всегда возвращает `num`, даже если оба аргумента `int`.

Деление на ноль возвращает `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `10 / 2` | `5.0` |
| `10 / 3` | `3.3333333333333335` |
| `10 / 6` | `1.6666666666666667` |
| `-5 / 2` | `-2.5` |
| `5 / -2` | `-2.5` |
| `-5 / -2` | `2.5` |
| `Type(10 / 3)` | `'num'` |
| `10.0 / 4.0` | `2.5` |
| `1 / 0` | `null` |
| `1.0 / 0.0` | `null` |

## Div(left, right)

`Div(left, right)` возвращает целую часть арифметического деления первого аргумента на второй.

Оба аргумента интерпретируются как действительные числа, то есть они не обязаны быть `int`.
Результат всегда `int`.

Дробная часть результата отбрасывается в сторону нуля. Деление на ноль возвращает `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Div(7, 2)` | `3` |
| `Div(7.1, 2.3)` | `3` |
| `Div(9, 3)` | `3` |
| `Div(-4, 3)` | `-1` |
| `Div(4, -3)` | `-1` |
| `Div(-4, -3)` | `1` |
| `Div(10, 3)` | `3` |
| `Div(10, 6)` | `1` |
| `Div(1, 0)` | `null` |
| `Type(Div(10, 3))` | `'int'` |
| `Type(Div(7.1, 2.3))` | `'int'` |
| `Type(Div(1, 0))` | `'int'` |

## Priority

Операторы соблюдают обычный математический приоритет: умножение и деление выполняются раньше сложения и вычитания. Скобки меняют порядок вычисления.

Примеры:

| Expression | Result |
| --- | --- |
| `2 + 2 * 2` | `6` |
| `(2 + 2) * 2` | `8` |
| `(-10 + 1).Sign()` | `-1` |
| `-10 + 1.Sign()` | `-9` |
