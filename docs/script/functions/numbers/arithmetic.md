# Arithmetic

Arithmetic operators выполняют базовые числовые операции.

## left + right

`+` складывает два числа.

Если оба аргумента `int`, результат `int`. Если хотя бы один аргумент `num`, результат `num`.

Если один из аргументов `null`, результат `null`, а nullability результата сохраняет тип второго аргумента.

Примеры:

| Expression | Result |
| --- | --- |
| `2 + 2` | `4` |
| `2.5 + 3.5` | `6.0` |
| `2.5 + 4` | `6.5` |
| `Type(3 + 3)` | `'int!'` |
| `2 + null` | `null` |
| `Type(2 + null)` | `'int'` |

## left - right

`-` вычитает правое число из левого.

Примеры:

| Expression | Result |
| --- | --- |
| `3 - 8` | `-5` |
| `3.0 - 8.5` | `-5.5` |

## -value

Unary `-` меняет знак числа.

Примеры:

| Expression | Result |
| --- | --- |
| `-4` | `-4` |
| `-3.0` | `-3.0` |
| `-0.0` | `0.0` |
| `-0` | `0` |

## left * right

`*` умножает два числа.

Примеры:

| Expression | Result |
| --- | --- |
| `-4.0 * 8.0` | `-32.0` |
| `-8 * -3` | `24` |

## left / right

`/` делит левое число на правое.

Для `int / int` используется целочисленное деление. Дробная часть отбрасывается в сторону нуля.

Для `num / num` используется дробное деление.

Деление на ноль возвращает `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `10 / 2` | `5` |
| `10 / 6` | `1` |
| `-5 / 2` | `-2` |
| `5 / -2` | `-2` |
| `-5 / -2` | `2` |
| `10.0 / 4.0` | `2.5` |
| `1 / 0` | `null` |
| `1.0 / 0.0` | `null` |

## Priority

Операторы соблюдают обычный математический приоритет: умножение и деление выполняются раньше сложения и вычитания. Скобки меняют порядок вычисления.

Примеры:

| Expression | Result |
| --- | --- |
| `2 + 2 * 2` | `6` |
| `(2 + 2) * 2` | `8` |
| `(-10 + 1).Sign()` | `-1` |
| `-10 + 1.Sign()` | `-9` |
