# Frac

`Frac` возвращает дробную часть числа.

## Frac(value)

`Frac(value)` возвращает остаток от деления `value` на `1`.

Для отрицательных чисел знак дробной части сохраняется.

Примеры:

| Expression | Result |
| --- | --- |
| `Frac(0.0)` | `0.0` |
| `Frac(10.0)` | `0.0` |
| `Frac(1.123)` | `0.123` |
| `Frac(-2.123456789)` | `-0.123456789` |
