# Mod, Rem

`Mod` и `Rem` возвращают остаток от деления целых чисел.

## Mod(input, modulus)

`Mod(input, modulus)` возвращает остаток от деления с поведением знака как у ClickHouse `MOD`.

Примеры:

| Expression | Result |
| --- | --- |
| `Mod(7, 2)` | `1` |
| `Mod(9, 3)` | `0` |
| `Mod(-4, 3)` | `-1` |
| `Mod(4, -3)` | `1` |
| `Mod(-4, -3)` | `-1` |

## Rem(input, modulus)

`Rem(input, modulus)` возвращает абсолютное значение остатка.

Из-за этого результат не сохраняет знак отрицательного делимого.

Примеры:

| Expression | Result |
| --- | --- |
| `Rem(10, 5)` | `0` |
| `Rem(6, 5)` | `1` |
| `Rem(-9, 5)` | `4` |
| `Rem(0, 5)` | `0` |
| `Rem(10, -3)` | `1` |
