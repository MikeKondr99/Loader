# Abs, Sign

`Abs` и `Sign` работают с `int` и `num`.

## Abs(value)

`Abs(value)` возвращает модуль числа.

Тип результата совпадает с типом входного значения.

Если вход равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Abs(1.5)` | `1.5` |
| `Abs(.0 - 1.5)` | `1.5` |
| `Abs(3)` | `3` |
| `Abs(-3)` | `3` |
| `Abs(null)` | `null` |

## Sign(value)

`Sign(value)` возвращает знак числа:

- `-1`, если число меньше нуля.
- `0`, если число равно нулю.
- `1`, если число больше нуля.

Результат всегда имеет тип `int`.

Если вход равен `null`, результат тоже `null`.

Примеры:

| Expression | Result |
| --- | --- |
| `Sign(0)` | `0` |
| `Sign(2)` | `1` |
| `Sign(-2)` | `-1` |
| `Sign(0.0)` | `0` |
| `Sign(2.1)` | `1` |
| `(-2.1).Sign()` | `-1` |
| `Sign(null)` | `null` |
