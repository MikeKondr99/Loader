# Constants

`E` и `Pi` возвращают математические константы типа `num`.

## E()

`E()` возвращает число Эйлера.

Примеры:

| Expression | Result |
| --- | --- |
| `E()` | `2.718281828459045` |
| `E() > 2.71` | `true` |
| `E() < 2.72` | `true` |
| `E() + 1` | `3.718281828459045` |
| `E() * 2` | `5.43656365691809` |
| `E() / 2` | `1.3591409142295225` |

## Pi()

`Pi()` возвращает число pi.

Примеры:

| Expression | Result |
| --- | --- |
| `Pi()` | `3.141592653589793` |
| `Pi() > 3.14` | `true` |
| `Pi() < 3.15` | `true` |
| `Pi() + 1` | `4.141592653589793` |
| `Pi() * 2` | `6.283185307179586` |
| `Pi() / 2` | `1.5707963267948966` |
