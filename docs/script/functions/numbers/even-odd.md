# Even, Odd

`Even` и `Odd` проверяют четность целого числа.

## Even(value)

`Even(value)` возвращает `true`, если число четное.

Примеры:

| Expression | Result |
| --- | --- |
| `Even(0)` | `true` |
| `Even(1)` | `false` |
| `Even(2)` | `true` |
| `Even(-1)` | `false` |
| `Even(-2)` | `true` |

## Odd(value)

`Odd(value)` возвращает `true`, если число нечетное.

Примеры:

| Expression | Result |
| --- | --- |
| `Odd(0)` | `false` |
| `Odd(1)` | `true` |
| `Odd(2)` | `false` |
| `Odd(-1)` | `true` |
| `Odd(-2)` | `false` |
