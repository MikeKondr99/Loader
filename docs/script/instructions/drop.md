# DROP

`DROP` удаляет ранее созданную script-таблицу.

## Синтаксис

```text
DROP table_name;
```

Для имен со спецсимволами используйте bracket-name:

```text
DROP [orders 2026];
```

## Пример

```ts
raw:
TEMP LOAD *
FROM Csv('orders.csv');

orders:
LOAD
  id.Int() AS id,
  amount.Num() AS amount
FROM raw;

DROP raw;
```

## Когда Выполняется

`DROP` выполняется во время исполнения сценария, когда executor доходит до этой инструкции.

Инструкция ищет таблицу в текущем контексте сценария по alias.

## Побочные Эффекты

`DROP` выполняет `DROP TABLE IF EXISTS` для физической ClickHouse-таблицы и удаляет `LoadedTable` из контекста сценария.

После `DROP` это имя можно использовать снова:

```ts
orders:
LOAD *
FROM Inline(x; 1);

DROP orders;

orders:
LOAD *
FROM Inline(x; 2);
```

## Ошибки

Если таблицы нет в контексте сценария, `DROP` падает с ошибкой:

```text
Таблица 'orders' не найдена среди загруженных LOAD таблиц.
```

Если физическое удаление в ClickHouse завершилось ошибкой, ошибка оборачивается как ошибка stage `DropTable`.

## Производительность

`DROP` полезен, если большая промежуточная таблица больше не нужна до конца сценария.

`TEMP LOAD` все равно очищается автоматически в конце сценария, но явный `DROP` освобождает таблицу раньше и освобождает alias для повторного использования.
