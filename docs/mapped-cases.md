# Mapped LOAD cases

Документ фиксирует доменную семантику `MAPPED LOAD` и `ApplyMap`.
Галочка означает, что поведение покрыто тестом и должно сохраняться.

## Базовая логика

- [x] `MAPPED LOAD` создает mapping-таблицу для lookup через `ApplyMap`.
- [x] Mapping-таблица не является обычным пользовательским результатом загрузки.
- [x] Mapping-таблица не отображается в результате выполнения script.
- [x] Mapping-таблица автоматически очищается после выполнения script.
- [x] `MAPPED LOAD` должен возвращать ровно два поля.
- [x] Первое поле `MAPPED LOAD` является ключом.
- [x] Второе поле `MAPPED LOAD` является значением.
- [x] `MAPPED LOAD *` допустим только если источник возвращает ровно два поля.
- [x] Дубли ключей в `MAPPED LOAD` схлопываются детерминированно: используется первое значение для ключа.
- [x] `ApplyMap` ищет только mapping-таблицы, созданные раньше текущего statement.
- [x] `ApplyMap` возвращает тип значения из второго поля mapping-таблицы.
- [x] Если ключ не найден, `ApplyMap` возвращает `null`.
- [x] Если сам ключ имеет значение `null`, `ApplyMap` возвращает `null`.
- [x] `null.ApplyMap('map')` без явного типа ключа запрещен; нужно писать явное приведение, например `null.Text().ApplyMap('map')`.
- [x] Если нужен fallback для отсутствующего ключа, используется обычный `Alt`, например `field.ApplyMap('map').Alt('Unknown')`.
- [x] `DROP map;` делает mapping-таблицу недоступной для следующих `ApplyMap`.

## Успешные сценарии

- [x] `MAPPED LOAD key, value FROM ...` создает mapping-таблицу.
- [x] `MAPPED LOAD * FROM ...` создает mapping-таблицу, если источник возвращает ровно два поля.
- [x] `ApplyMap` поддерживает строковый ключ.
- [x] `ApplyMap` поддерживает целочисленный ключ.
- [x] `ApplyMap` поддерживает явно типизированный null-ключ.
- [x] `ApplyMap` поддерживает числовое значение.
- [x] `ApplyMap` поддерживает строковое значение.
- [x] `ApplyMap` поддерживает boolean значение.
- [x] `ApplyMap` поддерживает datetime/date-like значение.
- [x] `ApplyMap` поддерживает time значение.
- [x] `ApplyMap` можно использовать в `SELECT`.
- [x] `ApplyMap` можно использовать в `WHERE`, если результат mapping имеет boolean тип.
- [x] `ApplyMap` можно использовать в `GROUP BY`.
- [x] `ApplyMap` можно использовать в `ORDER BY`.
- [x] `ApplyMap(...).Alt(...)` возвращает fallback, если ключ отсутствует.
- [x] Mapping-таблица может быть создана из inline-источника.
- [x] Mapping-таблица может быть создана из file source.
- [x] Mapping-таблица может быть создана из database source.

## Ошибки

- [x] `MAPPED LOAD` с одним явным полем должен завершаться ошибкой.
- [x] `MAPPED LOAD` с тремя и более явными полями должен завершаться ошибкой.
- [x] `MAPPED LOAD *` из источника без полей должен завершаться ошибкой.
- [x] `MAPPED LOAD *` из источника с одним полем должен завершаться ошибкой.
- [x] `MAPPED LOAD *` из источника с тремя и более полями должен завершаться ошибкой.
- [x] `ApplyMap('missing')` должен завершаться ошибкой, если mapping-таблица не найдена.
- [x] `ApplyMap('normal_table')` должен завершаться ошибкой, если таблица существует, но не является mapping-таблицей.
- [x] `ApplyMap('map')` после `DROP map;` должен завершаться ошибкой.
- [x] `ApplyMap` должен завершаться ошибкой, если тип ключа не соответствует типу первого поля mapping-таблицы.
- [x] `null.ApplyMap('map')` должен завершаться ошибкой, потому что тип ключа не указан явно.
- [x] `ApplyMap` с нестроковым именем mapping-таблицы должен отклоняться обычной системой функций.

## Открытые решения

- [x] Чтение `FROM map` для mapping-таблицы разрешено.
- [x] `Union(map, table)` для mapping-таблицы разрешен.
- [x] `Join(map, table, ...)` для mapping-таблицы разрешен.
- [ ] Запрет одинаковых alias таблиц решается отдельно для всех видов LOAD, не только для `MAPPED LOAD`.
